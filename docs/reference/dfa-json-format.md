# DFA JSON形式

## 概要

FA Design Gameが内部で扱うDFAのJSON形式を定義します。
提出画面では、専用フォームの入力からこの形式のデータを生成する想定です。
ただし、[ページ構成](../product/pages.md)には「DFA JSON入力欄」と記載されているため、入力方式は実装前に確定する必要があります。

## データ例

```json
{
  "states": ["q0", "q1"],
  "alphabet": ["0", "1"],
  "start": "q0",
  "accept": ["q0"],
  "transitions": {
    "q0": { "0": "q1", "1": "q1" },
    "q1": { "0": "q0", "1": "q0" }
  }
}
```

## フィールド

### `states`

DFAの状態の集合です。
1つ以上の状態を指定します。

専用フォームを使用する場合は、初期状態として空の入力欄を1つ表示し、必要に応じて入力欄を追加できるようにします。

### `alphabet`

DFAが扱う入力文字の集合です。
問題ごとに定義された値を使用します。

専用フォームを使用する場合は、問題データから自動で設定し、ユーザーによる入力を求めません。

### `start`

DFAの開始状態です。
`states`に含まれる状態を1つ指定します。

専用フォームを使用する場合は、開始状態の入力欄を1つ表示し、入力欄は追加できないようにします。

### `accept`

DFAの受理状態の集合です。
受理状態がない場合は、空の配列を指定できます。

専用フォームを使用する場合は、必要に応じて入力欄を追加できるようにします。

### `transitions`

各状態と入力文字に対応する遷移先を指定します。

専用フォームを使用する場合は、`states`と`alphabet`の組み合わせごとに遷移先の入力欄を自動で表示します。

## 入力時の要件

- `states`には1つ以上の状態を指定する
- `start`には`states`に含まれる状態を1つ指定する
- `accept`には0個以上の受理状態を指定する
- `transitions`には、各状態と各入力文字に対応する遷移先を指定する
