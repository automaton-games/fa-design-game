# トリアージラベル

各スキルは、以下の5つの標準的なトリアージ上の役割を使用します。このファイルでは、その役割をこのリポジトリのGitHubラベルへ対応付けます。

| スキル上の役割 | このリポジトリのラベル | 意味 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | メンテナーによる評価が必要 |
| `needs-info` | `needs-info` | 報告者からの追加情報を待っている |
| `ready-for-agent` | `ready-for-agent` | 仕様が十分に明確で、人による補足なしにAgentが対応できる |
| `ready-for-human` | `ready-for-human` | 人による実装が必要 |
| `wontfix` | `wontfix` | 対応しない |

スキルが役割（例: 「Agent対応可能ラベルを付ける」）に言及した場合は、この表に対応するラベル名を使用してください。

GitHub上のラベル名を変更した場合は、この表の「このリポジトリのラベル」列も更新してください。
